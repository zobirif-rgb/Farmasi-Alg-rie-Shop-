# Farmasi Algérie Shop

Site de vente Farmasi Algérie — https://farmasialgériestor.online

Ce dépôt contient le code du site publié sur Spacefast (espace `farmasi-algerie-shop`).

- `index.html` : boutique (catalogue, slider, panier, commande)
- `commandes.html` : page des commandes
- `images/` : logo, slides, produits et pages du catalogue
- `intro.mp4`, `poster.jpg` : vidéo d'introduction
- `sf.jsonc` : configuration Spacefast
